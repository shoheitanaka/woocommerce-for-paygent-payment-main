# はじめる前に（準備するもの）

## やること

決済の設定を始める前に、必要なものを揃えておきましょう。慌てて途中で作業が止まらないよう、
このページでチェックしておくことをおすすめします。

## 1. WooCommerce でネットショップが構築されていること

本マニュアルは決済導入に特化しているため、WooCommerce 自体の基本的な使い方（商品登録、配送方法の設定など）は解説していません。
まだネットショップの土台ができていない場合は、先に WooCommerce の基本設定を済ませておいてください。

## 2. ペイジェント社との契約

PAYGENT for WooCommerce は、株式会社ペイジェントが提供する決済サービスを WooCommerce に組み込むためのプラグインです。
そのため、**プラグインを入れただけでは決済は使えず、別途ペイジェント社との契約が必要**になります。

- 実際にテスト環境で決済の動作確認を行う場合も、契約が必要です。
- まずは画面の見た目だけ確認したい、という場合はペイジェントが提供するデモ環境の利用申し込みができます。
  （申込ページ: `https://wc.artws.info/payment-demo-apply/` ）
- 設定方法が分からず不安な場合は、有償のセットアップサポートも用意されています。
  （サポート案内ページ: `https://wc.artws.info/product/payment-support/` ）

契約が完了すると、ペイジェント社から以下のような情報が発行されます。これらは次の章以降で管理画面に入力していきます。

- マーチャントID
- 接続ID
- 接続パスワード
- トークン生成鍵
- クライアント証明書ファイル（`.pem` 形式）

これらは通常、**本番環境用**と**テスト環境用**の2セットが発行されます。混同しないよう、ペイジェント社から届いた書類やメールを手元に用意しておきましょう。

> **より詳しい資料が欲しいとき**: 各決済手段の詳細な導入補足資料や仕様書は、ペイジェント社の加盟店管理者サイト（[https://portal.paygent.co.jp/n/manage-m/login.html](https://portal.paygent.co.jp/n/manage-m/login.html)）にログインし、「マニュアル／仕様書」から入手できます。ログインアカウントは契約時にペイジェント社から発行されます。

## 3. 利用したい決済手段を決めておく

PAYGENT for WooCommerce では、以下の決済手段に対応しています。決済手段によっては個別の審査や追加契約が必要な場合があるため、
どの決済手段を導入したいか事前に整理しておくとスムーズです。

- クレジットカード決済（分割払い・3Dセキュアなどに対応）
- コンビニ決済
- PayPay
- Paidy（あと払い）
- 楽天ペイ
- 銀行ネット
- ATM決済（仮想口座）
- キャリア決済（auかんたん決済・d払い・ソフトバンクまとめて支払い 等）
- クレジット決済（多通貨）

はじめて決済を導入する方は、まず**クレジットカード決済**と、日本でよく使われる**コンビニ決済**や**PayPay**から導入するのがおすすめです。

## 4. サイトの常時SSL化（HTTPS）

決済情報を安全にやり取りするため、本番運用を始める前にサイト全体を HTTPS 化しておきましょう。
多くのレンタルサーバーでは無料のSSL証明書を利用できます。

## 準備チェックリスト

- [ ] WooCommerce でネットショップが構築されている
- [ ] ペイジェント社と契約している（またはデモ環境の申し込みをしている）
- [ ] 本番環境用・テスト環境用のマーチャントID等の情報が手元にある
- [ ] クライアント証明書ファイル（`.pem`）が手元にある
- [ ] 導入したい決済手段を決めている
- [ ] サイトのSSL化（HTTPS）が済んでいる、または対応予定である

準備ができたら、次は [プラグインのインストールと有効化](02-installation.md) に進みましょう。
