# PayPay決済の設定

## やること

日本国内で広く普及しているスマホ決済「PayPay」を設定します。設定項目が少なく、最も手軽に導入できる決済手段の一つです。

前提として、[基本設定（加盟店情報の入力）](03-basic-settings.md) で「ペイペイ決済(ペイジェント)」にチェックを入れて保存済みであることを確認してください。

## PayPay決済の仕組み

1. お客様がチェックアウト画面で「PayPay」を選び、注文を確定する
2. PayPay の決済画面（アプリまたはWeb）にリダイレクトされる
3. お客様が PayPay アプリで支払いを認証する
4. 自動的にネットショップのサイトに戻り、注文が「処理中」になる（この時点では支払いの承認までで、売上はまだ確定していません）
5. ショップ側で注文ステータスを「完了」に変更すると、ペイジェント側に売上指示が送られ、売上が確定する

> **重要（売上の確定を忘れずに）**: PayPay決済は、お客様の支払い操作が終わった時点では「支払いの承認（オーソリ）」までしか行われていません。商品の発送などが済んだら、必ず注文ステータスを「完了」に変更してください。この操作をきっかけにペイジェントへ売上指示が送られます。「完了」に変更したあとは、注文詳細画面の「注文メモ」に売上処理の成功が記録されていることを確認してから、その注文の売上を確定済みとして扱ってください（失敗のメモが記録されている場合は、売上が確定していません。エラー内容を確認のうえ再度操作するか、ペイジェント社にお問い合わせください）。

## 手順

### 1. 決済設定タブを開く

「WooCommerce」→「設定」→「決済」タブから、「ペイペイ決済(ペイジェント)」の「管理」ボタンをクリックします。

### 2. 項目を設定する

![PayPay決済の設定画面](images/10-paypay-settings.jpg)

- **有効化/無効化**: チェックを入れるとお客様に表示されます。
- **タイトル**: チェックアウト画面での表示名です（例: 「PayPay」）。
- **説明**: 補足の説明文です。
- **注文ボタンの文字**: 注文確定ボタンの文言です。
- **デバッグモード**: 通常はチェックを外したままにしておきます。動作確認中にエラーの詳細を確認したい場合のみ有効にします。

### 3. 設定を保存する

画面下部の「変更を保存」ボタンをクリックします。

## テスト環境での確認方法

PayPayは、実際のスマホアプリの代わりに、ペイジェント社が用意するテスト専用のPayPayログイン画面を使って動作確認ができます。
[基本設定](03-basic-settings.md) の「試験環境」にチェックが入っている状態で、以下の手順を試してください。

1. サイトのチェックアウト画面で「PayPay」を選び、注文を確定します。
2. PayPayのテスト用ログイン画面にリダイレクトされます。画面に「こちらをクリック」のようなリンクがあれば、それをクリックしてログインフォームを表示させます。
3. 電話番号とパスワードを入力し、「ログイン」をクリックします。テスト用のログイン情報は次の通りです（実際のPayPayアカウントではなく、この専用のテスト値を使います）。
   - 電話番号: `09081818181`
   - パスワード: `PayPay8181`
4. ワンタイムパスワード（OTP）の入力画面に進みます。テスト用のOTPは `1234` です。入力して「認証する」をクリックします。
5. 支払い方法の選択画面が表示されたら「支払う」をクリックします。
6. サイトに自動的に戻り、注文が完了することを確認します。

> **注意**:
> - テスト環境はペイジェント社の他の利用者と共有されています。金額の重複を避けるため、テスト注文は**1円**など少額で行い、確認が終わったら**その日のうちに**[注文の管理](08-order-management.md) の手順で返金しておきましょう。
> - PayPay側の週次メンテナンスにより、**木曜20:30〜金曜0:00（日本時間）はテストができない**場合があります。この時間帯を避けてテストしてください。
> - 上記のテスト用ログイン情報は変更される場合があります。うまくログインできない場合は、ペイジェント社の加盟店管理者サイトで最新の情報をご確認ください。

## ポイント・注意

- PayPay はスマートフォンでの利用が中心です。パソコンからの注文でも、お客様のスマホの PayPay アプリと連携して支払いが完了します。
- 本番環境では、お客様は上記のテスト用情報ではなく、ご自身のPayPayアプリで認証を行います。

次は [その他の決済手段](07-other-payment-methods.md) を確認しましょう。
