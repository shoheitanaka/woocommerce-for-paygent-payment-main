# テスト環境での動作確認の進め方

## やること

実際にお客様に決済を利用してもらう前に、テスト環境（試験環境）で決済の一連の流れをしっかり確認します。
この章では確認の進め方の全体像を説明し、次章以降で決済手段ごとの具体的なテスト方法を解説します。

## テスト環境とは

テスト環境（試験環境）は、実際のお金を動かさずに決済の流れを確認できる練習用の環境です。
[基本設定（加盟店情報の入力）](03-basic-settings.md) で入力した「試験環境」のマーチャントIDなどの情報を使って動作します。

「ペイジェント設定」画面の「基本設定」にある**「試験環境」チェックボックス**がオンになっている間は、
サイト全体がテスト環境として動作します。

![「試験環境」チェックボックスがオンになっている基本設定画面](images/02-paygent-setting-basic.jpg)

> **試験環境に関する詳しい資料について**: 試験環境の申込方法や試験環境ツールの詳細な仕様は、ペイジェント社の加盟店管理者サイト（[https://portal.paygent.co.jp/n/manage-m/login.html](https://portal.paygent.co.jp/n/manage-m/login.html)）にログインし、「マニュアル／仕様書 ＞ 試験環境の利用方法」からダウンロードできます。より詳細なテストパターンを確認したい場合はあわせてご参照ください。

## テストの全体像

決済手段によって、テストのしやすさが異なります。大きく2つのグループに分かれます。

| グループ | 決済手段の例 | テスト方法 |
| --- | --- | --- |
| その場で結果が返る決済 | クレジットカード | 決済結果を制御できるテスト用のカード番号を使って注文するだけで、成功・失敗・3Dセキュア認証などの結果をその場で確認できます |
| 入金確認に時間がかかる決済 | コンビニ決済、ATM決済、銀行ネット | 通常は実際の入金を待つ必要がありますが、ペイジェントが提供する「試験環境ツール」を使うことで、入金があった状態を擬似的に作り出してテストできます |

それぞれの具体的な手順は、次の章で解説します。

- [クレジットカード決済の詳しいテスト方法](10-testing-credit-card.md)
- [試験環境ツールを使った他の決済手段のテスト](11-testing-other-methods.md)

## 確認しておきたい共通のポイント

決済手段に関わらず、テスト注文の際は以下の点を確認しましょう。

- チェックアウト画面に、設定した決済手段がきちんと表示されるか
- 決済手段名やタイトル・説明文が意図した通りに表示されているか
- 決済完了後、正しく注文完了ページに遷移するか
- [注文の管理](08-order-management.md) で解説した注文詳細画面に、注文メモとして決済結果（取引ID等）が記録されているか
- （コンビニ決済の場合）支払い番号がきちんと発行され、案内文が正しく表示されるか

テストが一通り終わったら、[本番環境への切り替え](12-going-live.md) に進みましょう。
