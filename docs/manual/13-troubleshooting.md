# よくあるトラブルと対処法

設定作業中や運用中によく発生するトラブルと、その対処法をまとめました。困ったときはまずこのページを確認してみてください。

> **このページで解決しない場合**: エラーコードの詳細な仕様や、決済手段ごとの詳しいエラー一覧は、ペイジェント社の加盟店管理者サイト（[https://portal.paygent.co.jp/n/manage-m/login.html](https://portal.paygent.co.jp/n/manage-m/login.html)）にログインすると「マニュアル／仕様書」からダウンロードできます。あわせてご確認ください。

## 「本番環境用のクライアント証明書(.pem)がアップロードされていません」という警告が表示される

「ペイジェント設定」画面の上部に、このような警告バナーが表示されることがあります。

**対処法**: [基本設定（加盟店情報の入力）](03-basic-settings.md) の「本番環境」セクションで、ペイジェント社から発行されたクライアント証明書（`.pem` ファイル）をアップロードしてください。テスト環境のみで作業している間はこの警告が出続けますが、動作には影響しません。

## チェックアウト画面に決済手段が表示されない

**確認ポイント**:

1. 「WooCommerce」→「ペイジェント設定」画面で、該当する決済手段にチェックが入っているか確認する
2. 「WooCommerce」→「設定」→「決済」タブでも、該当する決済手段が「有効化」されているか確認する（上記1と2の両方が有効になっている必要があります）
3. 決済手段によっては、販売する商品や配送先国によって表示条件が異なる場合があります

## 決済がエラーになる／完了しない

**確認ポイント**:

1. 「試験環境」のチェックと、入力している認証情報（マーチャントIDなど）が、テスト用・本番用のどちらか一致しているか確認する
2. マーチャントID・接続ID・接続パスワードなどの入力欄に、余分な空白や改行が入っていないか確認する
3. クレジットカード決済で3Dセキュア2.0を有効にしている場合、ペイジェント社への事前申請が完了しているか確認する
4. 各決済手段の設定画面にある「デバッグモード」を一時的に有効にし、WooCommerce のログ（「WooCommerce」→「ステータス」→「ログ」）でエラーの詳細を確認する

## コンビニ・銀行ネット・ATM決済の入金が注文に反映されない

これらの決済手段は、入金確認の通知（決済情報差分通知）を受け取ることで、自動的に注文ステータスが更新される仕組みです。

**確認ポイント**:

1. 「ペイジェント設定」画面の「決済情報差分通知URL」に表示されているURLが、ペイジェント社の加盟店管理サイト側にも正しく登録されているか確認する（登録方法はペイジェント社にお問い合わせください）
2. サーバー側のセキュリティ設定（ファイアウォールなど）で、外部からのアクセスがブロックされていないか確認する
3. 反映まで多少の時間差が生じることがあるため、しばらく時間を置いてから再度確認する

## エラーコード別の対処法

デバッグログやWebサーバーのエラーログに、以下のようなエラーコードが表示されている場合の対処法です。

| エラーコード | よくある原因 | 対処法 |
| --- | --- | --- |
| P001 / P002 | マーチャントID・接続ID・接続パスワードのいずれかが間違っている | [基本設定](03-basic-settings.md) で入力した値が、ペイジェント社から発行された値と一致しているか確認してください |
| P006 | 決済に必要な入力項目が不足している | 決済手段の設定画面で、必須項目（タイトルや対応ブランドなど）に入力漏れがないか確認してください |
| P007 | 利用しようとした決済手段が未契約になっている | [基本設定](03-basic-settings.md) で有効化した決済手段について、ペイジェント社との契約・審査が完了しているか確認してください |
| P015 | サーバーの送信元IPアドレスが、ペイジェントに登録されているIPアドレスと異なる | レンタルサーバー側のIPアドレス（[基本設定](03-basic-settings.md) の「基本設定」に表示される接続IPアドレス）が正しく登録されているか、サーバー会社およびペイジェント社に確認してください |
| E02004 | クライアント証明書が正しく読み込めていない（証明書エラー） | [基本設定](03-basic-settings.md) でアップロードしたクライアント証明書（`.pem`）が、有効期限切れ・破損・本番用とテスト用の取り違えになっていないか確認してください。証明書ファイルの読み込み権限（パーミッション）も確認してください |
| E02005 | 決済センターへの接続エラー（DNS・ファイアウォール等） | サーバーのDNS設定、ファイアウォール設定で、ペイジェントのURLへの通信が許可されているか確認してください |
| 画面に「HTTP 500 内部サーバーエラー」または「取引情報が正しくありません。」と表示される | 上記のP015と同様、送信元IPアドレスの不一致が主な原因 | 上記「P015」の対処法をご確認ください |

## 決済ページの表示が遅い・固まってしまう

サイトが常時HTTPS化されていない場合、決済関連の画面表示が極端に遅くなることがあります。

**対処法**: サイト全体をHTTPS（SSL）化してください。多くのレンタルサーバーでは無料のSSL証明書を利用できます。

## それでも解決しない場合

上記で解決しない場合は、以下の情報を添えてお問い合わせください。

- 該当するエラーの各種ログファイルの内容
- 該当する決済手段名（クレジット決済やコンビニ決済など）
- 該当する注文の注文番号と注文時間

お問い合わせ先:

- ペイジェント決済導入サポートフォーム: `https://wc.artws.info/paygent-support/`
- 設定方法についてご自身での解決が難しい場合は、有償のセットアップサポートも利用できます。（サポート案内ページ: `https://wc.artws.info/product/payment-support/` ）
- 決済処理そのもの（審査状況、対応ブランドなど）に関するお問い合わせは、契約しているペイジェント社の窓口にご確認ください。
