# このマニュアルについて

## 目的

このマニュアルは、**初めてネットショップを開設し、初めて決済を導入する方**を対象に、
WooCommerce 用プラグイン「PAYGENT for WooCommerce」の設定方法を、実際の管理画面のスクリーンショットとともに
1 ステップずつ解説するものです。

「専門用語が多くてよく分からない」「どこを設定すればいいか不安」という方でも迷わず進められるよう、
各章を短く区切り、実際に操作する画面のキャプチャを添えています。

## このマニュアルで学べること

- PAYGENT for WooCommerce プラグインのインストールと有効化
- ペイジェント社から発行される契約情報（マーチャントIDなど）の入力方法
- クレジットカード・コンビニ決済・PayPay など主要な決済手段の設定方法
- 注文の確認・返金・キャンセルといった日常的な運用操作
- テスト環境での動作確認から、本番環境への切り替え方法
- よくあるトラブルとその対処法

## 覚えておきたい用語

はじめに、マニュアル中でよく出てくる言葉を簡単に説明します。分からなくなったら、このページに戻ってきてください。

| 用語 | かんたんな説明 |
| --- | --- |
| 決済代行会社 | クレジットカード会社やコンビニなど、様々な支払い方法をまとめて中継してくれる会社。本マニュアルでは「ペイジェント（Paygent）」を指します。 |
| マーチャントID / 接続ID / 接続パスワード | ペイジェントと契約すると発行される、いわば「お店の会員証」のようなID・パスワードです。決済を行うために必須です。 |
| 本番環境 | 実際にお客様がお金を支払う、本番用の設定です。 |
| 試験環境（テスト環境） | 実際のお金を動かさずに、決済の流れを確認できる練習用の設定です。 |
| ゲートウェイ | 「クレジットカード決済」「コンビニ決済」のように、決済手段ごとに用意されている個別の設定単位のことです。 |
| 加盟店管理者サイト（ペイジェントポータル） | ペイジェント社が加盟店向けに提供する管理サイトです。契約情報の確認や各種申込みのほか、より詳しい仕様書・マニュアル類もここからダウンロードできます。 |

> **ペイジェント社発行の詳しい資料について**: このマニュアルでカバーしきれない、より詳細な仕様書やマニュアル（決済手段ごとの導入補足資料、エラーコード一覧など）は、ペイジェント社の加盟店管理者サイト（[https://portal.paygent.co.jp/n/manage-m/login.html](https://portal.paygent.co.jp/n/manage-m/login.html)）にログインすると「マニュアル／仕様書」から入手できます。ログイン情報は契約時にペイジェント社から案内されます。

## マニュアルの読み方

各章は次のような構成になっています。

- **やること**: その章で何を設定するのかの概要
- **手順**: 実際の管理画面を見ながらの操作ステップ
- **ポイント・注意**: つまずきやすいポイントや、初心者が見落としがちな注意点

次の章「[はじめる前に（準備するもの）](01-prerequisites.md)」から、実際に準備を始めましょう。
