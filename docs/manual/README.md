# PAYGENT for WooCommerce 導入マニュアル

初めてネットショップを開設し、日本国内向けの決済を初めて導入する方向けに、
「PAYGENT for WooCommerce」プラグインの設定方法をステップバイステップで解説するマニュアルです。

## こんな方におすすめ

- WooCommerce でネットショップを構築した（している）が、決済手段の導入は初めて
- 「マーチャントID」「接続ID」といった専門用語に馴染みがない
- 管理画面のどこを触ればよいか、実際の画面を見ながら確認したい

## ご注意

- 本マニュアルは PAYGENT for WooCommerce の**決済導入・設定**に特化しています。WooCommerce 自体の基本操作（商品登録、配送設定など）は対象外です。
- 掲載している管理画面のスクリーンショットは検証用環境のものです。実際の画面はプラグインのバージョンやテーマによって多少異なる場合があります。
- 決済手段の利用には、株式会社ペイジェントとの契約（審査あり）が必要です。詳しくは [はじめる前に（準備するもの）](01-prerequisites.md) をご覧ください。
