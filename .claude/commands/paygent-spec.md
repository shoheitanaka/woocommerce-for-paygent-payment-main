# Paygent 仕様書検索

`2025docs/` 配下のPaygent公式仕様書PDFを `pdftotext` + `grep` で検索し、該当箇所を提示する。
**仕様書PDFがコードよりも正**（CLAUDE.md参照）。

## 引数

```
$ARGUMENTS
```

- 1つ目以降: 検索キーワード（エラーコード `33002`、電文種別 `421`、パラメータ名 `repayment_amount`、日本語語句 `該当データなし` など）
- 決済手段名（PayPay / docomo / paidy / 楽天 / コンビニ / ATM など）が含まれていれば、下の対応表で検索対象PDFを絞り込む。なければ共通仕様書＋主要別紙を横断検索する

## 検索手順

1. 対応表から対象PDFを決める（決済手段の指定がなければ★印の共通仕様書は必ず含める）
2. 次の形で検索する（`-layout` は表組みの判読に必須）:

   ```bash
   pdftotext -layout "<PDFパス>" - 2>/dev/null | grep -n -B3 -A8 "<キーワード>"
   ```

3. ヒットした行番号周辺を `sed -n '<開始>,<終了>p'` で広めに読み、表の場合はヘッダ行まで遡って読む
4. 結果は「PDF名・該当セクション・要点（表は整形して抜粋）」の形で報告する。ヒットなしの場合は
   検索した対象PDF一覧を示し、キーワードの表記ゆれ（例: 半角/全角、送り仮名）を変えて再検索する

## 注意

- `pdftotext` が無い場合は `brew install poppler` を案内する
- 表組みはpdftotextで崩れることがある。数値・必須区分を引用するときは前後を広めに読んで文脈を確認する
- 検索結果を根拠に回答するときは「仕様書名＋セクション名」を必ず添える
