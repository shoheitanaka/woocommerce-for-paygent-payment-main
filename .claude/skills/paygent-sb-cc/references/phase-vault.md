# Phase vault — カード保存の登録/削除・保存カード注文の返金/通知

依頼項目4〜5に対応。SKILL.md の Phase 0 完了が前提。
CC設定 `store_card_info=yes` が必要（noなら記録して変更し、終了時に戻す）。
3DS2は有効のまま実施する（3DS2経由のカード保存を確認するのが目的）。

## 1. カード保存の登録（注文経由）

Block・クラシックの両方で実施:

1. チェックアウトで新規カード入力＋名義人 `BAVYA`（RB成功）＋
   「カード情報を保存」チェックON → 3DS2フリクションレス → 決済成功
2. チャレンジ経由でも1回: 名義人 `BAVCA`＋保存ON → 認証画面パスワード `14012` → 成功
3. Block側は保存チェックボックスが**WC Blocksネイティブの1つだけ**表示されること
   （二重表示はNG）
4. マイアカウント→お支払い方法に「Visa（下4桁）」が表示されること
5. 注文詳細の支払い方法が「クレジットカード決済」のままであること

マイアカウント→お支払い方法に「支払い方法を追加」がある場合は、そこからの
登録フローも1回確認する（未提供ならその旨を記録）。

## 2. 保存カードでの決済

Block・クラシックの両方で実施:

1. チェックアウトで保存済みカード（トークン行）を選択＋CVC入力＋
   名義人パターン（`BAVYA`）→ 3DS2 → 決済成功
2. Blockはネイティブのトークン行（`wc-paygent_cc-payment-token` 経由）で
   validate_fields に弾かれないこと
3. 作成された注文は次の返金試験に使う

## 3. 保存カード注文の返金・キャンセル・通知（依頼項目5）

このフェーズで作成した注文（保存時注文＋保存カード決済注文）に対して:

| 操作 | 手順 | 確認 |
| --- | --- | --- |
| 部分返金 | 注文詳細→返金→一部金額 | 成功・注文メモ・返金メール1通 |
| 全額返金 | 別注文で全額返金 | ステータス=返金済み・メール1通 |
| キャンセル | 別注文（授権のみが残っていればそれ）をキャンセル | 成功・メール1通 |

返金/キャンセルしても**保存済みカード（トークン）は削除されない**ことを
マイアカウントで確認する。

## 4. カード削除

1. マイアカウント→お支払い方法→削除 → 一覧から消えること
2. 削除後にチェックアウトを開き、削除済みトークンが選択肢に残っていないこと
3. debugログ（WooCommerce→状態→ログ）またはPaygent応答で、Paygent側の
   顧客カード削除電文が成功していることを確認できれば記録する
4. 削除後、過去注文の表示・返金操作が壊れないこと（注文詳細を開いて確認）

## 5. メール確認

各操作後にWP Mail Loggingで、対象イベントのメールが**各1通のみ**
（2重送信・未送信なし）であることを確認して一覧化する。
