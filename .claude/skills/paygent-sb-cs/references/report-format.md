# レポート様式 — sandbox-cs-YYYYMMDD.md

保存先: リポジトリ直下 `report/`。ファイル名は `sandbox-cs-YYYYMMDD.md`
（同日2回目以降は `-2` 等を付加）。

> **初回運用ルール**: report/ に `sandbox-cs-*.md` が存在しない初回実行時は、
> この様式でドラフトを作成してユーザーとレビューし、確定した形式を本ファイルに
> 反映してテンプレートとして固定する。以後はここが正。

## 記載ルール

- 判定は ✅（期待通り）/ ❌（問題）/ ⚠️（要確認・設定依存）/ ➖（対象外）で統一。
- 問題には必ず注文番号・画面・再現手順を添える（後日の再検証を可能にする）。
- 設定を変更して実施した項目は、変更内容と復元済みであることを明記する。
- **試験環境ツールのマーチャント接続パスワードの値は記載しない**（SKILL.md
  絶対ルール8）。
